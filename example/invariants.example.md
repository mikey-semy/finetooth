# Инварианты проект автора

Правила, по которым написан этот проект. Нарушение любого из них — находка,
даже если код работает. Этот файл вклеивается в промпт каждому агенту ревью;
он сознательно короткий, детали — в `CLAUDE.md` и `docs/architecture/ADR.md`.

## Контекст, меняющий оценку находок

- **Продакшена ещё нет, пользователей нет, legacy-данных нет.** Заказчик получит
  чистую установку. Поэтому «так было в старых данных», «сломает существующие
  ссылки», «админ мог ввести это раньше» — НЕ оправдание для послабления
  проверки. Если сид противоречит правилу — чинится сид.
- **Целевой масштаб — 3000+ сотрудников**, а не 240 техников. Оценивай запросы и
  списки по этой цифре.
- **Заказчик один, и он реальный.** Сиды и фикстуры должны быть его настоящей
  конфигурацией, а не выдуманными демо-данными.
- **Никаких полумер.** Компромиссный фикс «чтобы пока работало» — сам по себе
  находка. Правильное решение выбирается даже если оно дороже.

## Бэкенд (Go)

1. **Слои:** `handler` → `usecase` → `infrastructure/repository`. Зависимости
   направлены внутрь; `domain/` не импортирует наружу.
2. **Аудит привязан к транзакции** (ADR-030): `audit.LogTx(txCtx, …)` ВНУТРИ
   `txm.WithTx`. Вызов `audit.Log()` вне транзакции допустим только для
   read-only побочек и с комментарием `// audit-log-allowed: <причина>`.
3. **Шесть конструкторов требуют `txm` и паникуют на nil**: `comment`,
   `savedview`, `notification`, `push`, `attachment`, `csat` (и новые по тому же
   образцу). Проверяй проводку зависимостей в `cmd/api` и `cmd/worker`.
4. **Публикация событий после коммита** — только `event.PublishDetached`
   (ADR-029). Прямой `broker.Publish(ctx, …)` с контекстом запроса теряет
   сигнал, когда пользователь закрыл вкладку.
5. **Фоновая работа — в `internal/worker/` под `cmd/worker`** (ADR-022).
   Горутины из HTTP-хендлеров запрещены.
6. **Пагинация курсорная** (ADR-003), не OFFSET. Курсор должен быть устойчив:
   сортировка с тай-брейком по уникальному полю.
7. **Время в UTC** (ADR-014). Первичные ключи — UUID v7.
8. **Мягкое удаление** для критичных сущностей (ADR-013): любой запрос обязан
   считаться с `deleted_at`.
9. **Оптимистическая конкуренция на смене статуса заявки**: клиент присылает
   `updated_at`, сервер отвечает 409 `TICKET_STALE_UPDATE`, если строка ушла
   вперёд.
10. **Идемпотентность** живёт на durable-ярусе Redis; кешируются только
    вердикты по содержимому запроса, но не 5xx/429/401/403/408/425.
11. **Файлы — в объектном хранилище** (ADR-015), не в PostgreSQL.
12. **Общие хелперы вместо копий**: `httputil.DecodeJSON`, `httputil.ClampLimit`,
    `pkg/pgerr` (никаких литералов SQLSTATE), `pkg/slug`,
    `passwordpolicy.BcryptCost` (единственный источник стоимости bcrypt),
    `hexcolor.NormalizeOptional`, `repository.Paginate`.

## База данных

13. **Мигрировавший файл неизменяем.** Изменения — только новой миграцией.
    Правка истории ломает `atlas.sum`.
14. **Гранты ролям в миграции — только через `CROSS JOIN roles WHERE r.id IN (…)`**,
    никогда по литеральному UUID.
15. **⚠️ И этого мало:** на чистой установке миграции идут ДО сидов, поэтому
    системной роли ещё нет и `CROSS JOIN` даёт ноль строк. Любой грант новой
    пары ресурс/действие системной роли ОБЯЗАН дублироваться в блоке этой роли
    в `database/seeds/001_roles_permissions.sql`.
16. **Новое право на чтение** дополнительно добавляется во встроенный пресет
    `readonly` в той же миграции.
17. **Сиды верхнего уровня едут в продакшен** (`db-init.sh` собирает их глобом).
    Демо-данные и ослабленные лимиты — только в `database/seeds/dev/`.

## Фронтенд (TypeScript)

18. **Никакого русского текста в коде** (ADR-020) — только через next-intl.
    Добавляя ключ `errors.*`, проверь, что он не переопределяет чужой: коды
    ошибок общие для всех модулей, и побеждает последний ключ в JSON.
19. **CSP собирается в `packages/shared/src/csp.ts`** одной функцией для обоих
    клиентов. `src/proxy.ts` только выдаёт заголовок с nonce. Директивы не
    дублируются в приложениях.
20. **`<audio>`/`<video>` — через `api.downloadBlob()` и `blob:`-URL**, не через
    presigned-ссылки (их блокирует CSP). Для `<img>` presigned допустимы.
21. **Base UI (не Radix).** `Select.Root` требует `items={[{value,label}…]}`,
    иначе триггер покажет сырой UUID; `value` обязан совпадать с отрисованным
    `SelectItem`, иначе Base UI сбросит значение.
22. **Контракт Go↔TS**: `packages/shared/src/contracts/backend.gen.ts`
    ГЕНЕРИРУЕТСЯ. Любой новый write-эндпоинт регистрируется в
    `ts_contract_test.go`, типизируется в `contracts.test-d.ts` и вызывается
    через типизированный `api.<method>`, а не сырой `api.post`.
23. **Переиспользуй общие хелперы**: `errorMessage(err, te)`, `<ConfirmDialog>`,
    `<EmptyState>`, `useCursorList`, `priority-styles`, `user-name`,
    `notification-time`, `TICKET_FIELD_ICONS`. Локальная копия — находка.
24. **Очередь офлайна ретраится вечно по сетевым причинам.** Бюджета попыток
    нет: `network` не меняет счётчик, `rate_limit` откладывает, `server`
    отступает экспоненциально, и только настоящий 4xx окончательно хоронит
    запись.

### Тесты

25. **Проверка пишется в обе стороны.** Тест, доказывающий, что запрещённое не
    проходит, без парного теста «разрешённое по-прежнему проходит» — половина
    проверки, и находкой является именно отсутствие второй половины. Это
    касается прав доступа, фильтров видимости, валидации и любого сужения
    выборки.
26. **Подделка в тесте не бывает мягче настоящей системы.** Мок, отвечающий
    успехом на отменённом контексте, разрешающий всё по умолчанию или не
    воспроизводящий отказ драйвера, — находка сама по себе: он делает зелёным
    то, что в проде падает.

## Что НЕ является находкой

- Стилистика, форматирование, вкусовые предпочтения по именам.
- «Можно было бы добавить тест» без указания конкретного непокрытого сценария.
- Предложения сменить библиотеку или архитектуру без конкретного дефекта.
- Замечания к сознательно замороженным исключениям, перечисленным в `CLAUDE.md`
  (например, `tickets:read_department` и другие имена, оставшиеся от
  переименования departments → service lines).
